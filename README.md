## Nama Project : WorkLeave

## Deskripsi Singkat Project
Sistem Informasi Manajemen Cuti Mitra Kerja  dengan nama WorkLeave merupakan aplikasi berbasis website yang dikembangkan untuk membantu proses pengajuan, persetujuan, perhitungan, pemantauan, dan rekapitulasi cuti mitra kerja secara terstruktur dan terkomputerisasi.

Project ini dikembangkan sebagai solusi terhadap proses pengelolaan izin dan cuti yang sebelumnya dilakukan secara manual menggunakan Microsoft Excel. Sistem dirancang untuk membantu mengurangi kesalahan dalam perhitungan sisa cuti serta mempermudah proses administrasi dan pemantauan pengajuan cuti.

##  Fitur
- Login dan autentikasi pengguna
- Pengajuan cuti secara online
- Persetujuan atau penolakan pengajuan cuti oleh admin
- Dashboard pemantauan kuota dan status cuti
- Riwayat pengajuan dan penggunaan cuti

## Requirements
- PHP
- Laravel
- Tailwind CSS
- PostgreSQL
